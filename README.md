# Software Engineering in the AI Era

Course website for first-year master's students in Electrical and Information Engineering, University of Nairobi. Prepared by Dr. Davies Rene Segera.

Open index.html, or publish the repository root with GitHub Pages (main branch, / root). All local URLs are relative and support a project URL. No installation or build is needed to serve the website.

## Contents

- Seven full modules covering sixteen weeks, with 84 revealable model answers and weekly laboratories.
- Revised course outline and eight printable PDFs. PDFs include all answers.
- Python examples, synthetic data, source-file viewers and downloadable examples ZIP.
- Editable Markdown sources and an offline study ZIP.
- Responsive navigation, print controls, accessible answer disclosures and links to the two related courses.

The original course materials remain in ../Course_2026_2027. Rebuild this publishing folder using ../.build/build_website.mjs after changing original materials. The builder reuses the existing Introduction to Programming course stylesheet and adds this course's reading styles. The original teaching content and supplied PDFs are preserved.

Extract downloads/software-engineering-study-materials.zip and open index.html for offline study. External fonts and references need internet; fallback fonts and core content work offline. The offline archive intentionally omits its own download link.

AI use follows the revised course outline: independent, guided and bounded development. The project is 20%, documentation and reflection 10%, and the final examination 70%.
